# Kaca

A static GitHub Pages reading site for five Rapi research notes. The English notes are copied from `irvan-putra/kaji` at source commit [`c6798ee`](https://github.com/irvan-putra/kaji/commit/c6798eea79001db880f75415c2d0017e3183dbb2). Kaji remains unchanged.

The site is built with Jekyll and deployed by GitHub Actions. Each note retains its source links, verification labels, and limits. The index marks proposal and unverified work clearly. This is a static reading site, not an app or live-data feed.
